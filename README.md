# Passive Radar Target Localisation

## Project Objective

This project develops a simulation-based passive radar
processing pipeline for 2D target localisation and tracking.

## Processing Pipeline

1. Signal Simulation
2. Clutter Suppression
3. Range-Doppler Processing
4. Target Detection
5. Target Localisation
6. Target Tracking
7. Evaluation
